# karimgamin2000-beep.github.io

Personal technical blog — combining Andrej Karpathy's distraction-free, text-first philosophy with modern developer UI polish (inspired by Codelynx).

## Stack

- **Framework**: [Astro](https://astro.build/)
- **Styling**: Tailwind CSS v4
- **Content**: Markdown / MDX (`src/content/posts/`)
- **Deployment**: GitHub Pages via GitHub Actions

## Local Development

```bash
npm install
npm run dev
```

## Writing a New Post

Create a `.md` or `.mdx` file in `src/content/posts/`:

```markdown
---
title: "Your Post Title"
description: "One-line summary."
pubDate: 2026-11-23
lang: "en" # or "fr"
tags: ["ai-engineering", "python"]
---
```
